## 2026-11-05 — M519: exact table grants on party_tables (#789)

- **What changed:** new migration `supabase/migrations/519_party_tables_exact_grants.sql` (was M487, renumbered above the Release V3 lock). It removes every grant to PUBLIC, `anon`, `authenticated` and `service_role` on `public.party_tables`, then grants back exactly what the app uses: `authenticated` SELECT, INSERT, UPDATE, DELETE (dashboard Parties page, guest-to-table RPCs, invite triggers); `service_role` SELECT (party reminders, invite triggers fired by RSVP and bot writes). No anonymous access. A self-check refuses to finish unless the grants are exactly this, there are no column-level grants and RLS is on.
- **Owner decision 2026-11-05:** `party_tables` only. `seating_resources` is left unchanged for a later grants clean-up, because its production grants differ from migration history and the Release V3 gate cannot record that difference yet.
- **Why the full reset:** production and staging start from different grants on this table; resetting every API role gives the same final state on both and matches the catalog oracle. Staging also gains the `service_role` SELECT that the reminder and RSVP paths need.
- **Unchanged:** RLS policies, columns, triggers, functions, application code, `seating_resources`.
- **Files:** the migration, `supabase/catalog-deltas/519_party_tables_exact_grants.json` (catalog oracle output), `lib/__tests__/party-tables-grants-519.pg.test.ts` (real PostgreSQL, from both the production and the staging starting grants: exact grants, allow and deny for each role, seated-guest RSVP trigger path, `seating_resources` untouched), `.github/workflows/ci.yml` (test required in the PG job, excluded from the plain unit run).
- **Apply:** staging, then production, each with its own Owner approval, as one whole-file statement named `519_party_tables_exact_grants`.
- **Could break:** any code path that reads or writes `party_tables` as `anon`, or writes it as `service_role` outside the SECURITY DEFINER seating function. None exists on main as of 2026-11-05 (code trace and Graphify).
